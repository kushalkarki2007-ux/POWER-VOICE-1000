POWER VOICE 1000 — starter web app

This is a browser-based recording/effects prototype, not an APK.
It records microphone audio and applies Deep Bass, Studio Mic, or Power Clear
processing to the recording. You can download or share the processed audio.

Important limitations:
- It does NOT replace the microphone in live WhatsApp calls or normal cellular calls.
- Microphone access usually requires the app to be served from HTTPS (or localhost).
- To install it like an app, upload the files to an HTTPS static host and open the
  link in Chrome on your Redmi 12, then use Chrome menu > Add to Home screen.
- Test with a short recording first. Browser support and share-sheet behavior vary.
